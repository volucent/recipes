## Preferences

- High protein
- Mediterranean / Mexican style
- Easy to make — minimal active cooking time
- Bulk prep friendly (3+ lbs chicken at once)
- **Equipment OK:** Instant Pot (preferred), oven, Dutch oven, cast iron pan, rice cooker, blender
- **Avoid:** complicated sauces across multiple pans
- **Chicken:** boneless skinless breast only. No thighs, no drumsticks.
